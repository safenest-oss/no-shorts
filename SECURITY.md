# Security policy

No Shorts collects no data and makes no network requests, but security reports are still welcome (for example, a way the extension could be abused, or a dependency or build issue).

## Reporting a vulnerability

Please use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue for security problems.

We aim to acknowledge reports within 7 days and to fix confirmed issues as soon as possible. We will credit you in the release notes if you wish.

## Supported versions

Only the latest release (the version in the Chrome Web Store) is supported.
