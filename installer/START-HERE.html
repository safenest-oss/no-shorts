No Shorts

A browser extension that removes YouTube Shorts (the short videos you can scroll through endlessly). Installation takes about 2 minutes and needs no technical knowledge.

Safe and private. The extension collects no data, makes no internet connections and only runs on youtube.com. All of its code is open and can be inspected.

Before you start

You need a computer (Windows or Mac) with the Google Chrome browser. The extension also works in Edge, Brave and Opera. It does not work in the YouTube app on a phone.

Installation

1

Unzip the downloaded file.

Windows: right-click the file, choose Extract All…, then Extract.
Mac: double-click the file.

You will get a normal folder with files in it. Do not install from inside the zip file – this is the most common cause of problems.

2

Move the folder to a permanent place.

For example to your Documents folder. The browser will keep using these files, so do not delete them after installing.

3

Open the extensions page in Chrome.

Click the address bar at the top of the browser, type the address below and press Enter:

chrome://extensions

In Edge type edge://extensions, in Brave brave://extensions.

4

Turn on “Developer mode”.

It is a switch in the top right corner of the page. Click it so that it turns blue. Don’t worry about the name – it only allows loading an extension from a file.

5

Click “Load unpacked”.

The button appears at the top left once Developer mode is on.

6

Choose the no-shorts folder.

Among the unzipped files you will find a folder named no-shorts. Select that folder (it has a file called manifest.json inside) and click Select Folder.

Done! A “No Shorts” card with its switch turned on should now appear in the list of extensions.

How to check that it works

Go to youtube.com and refresh the page (press F5). You should see that:

  • the home page has no “Shorts” section between the videos,
  • the menu on the left has no “Shorts” item,
  • channels have no “Shorts” tab,
  • a link to a Short opens like a regular video.

Want to compare? Turn off the switch on the “No Shorts” card in chrome://extensions, refresh YouTube and see the difference. Then turn it back on.

Good to know

When you restart the browser, Chrome may show a message about developer mode extensions. Choose to keep them (do not disable). This message will go away once the extension is available in the official Chrome store.

Installing for a child

The extension stops working if a child removes or disables it. So it is best to:

  • install it on an account that your child cannot change, for example a profile supervised with Google Family Link,
  • talk to your child about why you use it. A conversation protects better than any tool.

Something not working?

  • I can’t see the “Load unpacked” button. Check that Developer mode is on (step 4).
  • Error “Manifest file is missing or unreadable”. You picked the wrong folder. Choose the one that directly contains the manifest.json file (the no-shorts folder).
  • A Short still shows up. YouTube changes its pages often. Please tell us: github.com/safenest-oss/no-shorts/issues
